Sudocean - Мобильный приложение для закупки инвентаря для морских судов
Приложение является онлайн магазином .
Функциональность: 
Авторизация и регистрация - все аккаунты хранятся в базе данных
3 основных окна после авторизации - История заказов, Список доступных товаров для добавления в корзину, Корзина со списком выбранных товаров 
Первое окно - История заказов. имеет список заказов конкретного авторизованного пользователя , имеет основную информацию - id, дата заказа, сумма заказа и статус(в процессе, завершено, отменено)
Второе окно - Список Товаров. На Данном окне отображаются все доступные товары для выбора, у каждого товара есть картинка, название и описание. возле каждого товара есть 2 кнопки в виде плюса и минуса которые отвечают за добавление и удаление товара из корзины соответственно  
Третье окно - Окно корзины. В этом окне отображается список выбранных товаров, поля для ввода адреса телефона и ФИО(сохраняется в кэше для устранения необходимости повторного ввода), итоговая сумма оплаты, кнопка оплатить, которая переводить на дополнительное окно оплаты.
Окно оплаты - генерируется qr-код для оплаты заказа собранной пользователем корзины , также отображается сумма итоговой оплаты
