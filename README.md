# SudOcean — Мобильное приложение для торговли (Интеграция с 1С)

**SudOcean** — это современное Android-приложение, предназначенное для автоматизации продаж морского оборудования. Ключевой особенностью является полная двусторонняя интеграция с учетной системой **1С:Предприятие** через собственный HTTP-сервис (REST API).

## 🚀 Основные возможности

### 👤 Управление пользователями
*   **Два типа контрагентов**: Поддержка Физических и Юридических лиц.
*   **Умная авторизация**: Вход по номеру телефона (для физ. лиц) или ИНН (для юр. лиц).
*   **Синхронизация профиля**: Изменение ФИО, телефона, КПП или Юр. адреса в приложении мгновенно обновляет карточку контрагента в 1С.

### 🛒 Торговый функционал
*   **Каталог товаров**: Автоматическая загрузка номенклатуры, описаний и актуальных цен из 1С.
*   **Управление корзиной**: Изменение количества товаров, удаление позиций и полная очистка.
*   **Оформление заказа**: Передача состава корзины в 1С с созданием реального документа «Заказ покупателя».
*   **Имитация оплаты**: Интегрированный экран процессинга («SudOcean Bank») для подтверждения транзакции.

### 📋 История и статусы
*   **Живая история**: Список заказов загружается напрямую из 1С.
*   **Детализация**: Возможность просмотреть состав любого старого заказа (товары, цены, количество).
*   **Синхронизация статусов**: Отображение актуального состояния заказа из 1С (Оплачен, В процессе, Отменен).
*   **Отмена заказов**: Возможность отменить неоплаченный заказ с автоматическим уведомлением сервера 1С.

## 🛠 Технологический стек

### Android (Frontend)
*   **Язык**: Kotlin
*   **Архитектура**: MVVM (Model-View-ViewModel)
*   **База данных**: Room (локальное кеширование для работы offline)
*   **Сеть**: Retrofit 2 + OkHttp (взаимодействие с 1С)
*   **Навигация**: Jetpack Navigation Component (Single Activity Architecture)
*   **UI**: Material Design 3, ViewBinding, Swipe-to-Refresh
*   **Анимации**: Android-gif-drawable

### 1С:Предприятие (Backend)
*   **Объекты**: Справочники (Контрагенты, Номенклатура), Документы (Заказы), Перечисления (Статусы).
*   **API**: Собственный HTTP-сервис с шаблонами:
    *   `GET /products` — отдача каталога.
    *   `POST /clients` — регистрация/обновление контрагента.
    *   `POST /orders` — прием заказа.
    *   `GET /orders` — отдача истории по `user_id`.
    *   `POST /orders/cancel` — программная отмена заказа.

## 📁 Структура проекта (Android)

*   `data/` — Слой данных: таблицы Room, DAO и репозиторий.
*   `models/` — ViewModel для бизнес-логики и связи UI с данными.
*   `network/` — Сетевой слой: описание API и настройка Retrofit.
*   `ui/` — Фрагменты и адаптеры списков.
*   `res/` — Ресурсы: макеты (XML), стили, цвета и изображения.

## ⚙️ Настройка и запуск

1.  **Сервер 1С**:
    *   Опубликовать базу на веб-сервере (Apache или IIS).
    *   Убедиться, что HTTP-сервис `MobileExchange` активен и доступен по локальной сети.
2.  **Конфигурация Android**:
    *   В файле `network/NetworkClient.kt` указать актуальный IP-адрес сервера 1С.
    *   Настроить `Basic Auth` (логин/пароль администратора 1С).
3.  **Сборка**:
    *   Android Studio 2024.1+
    *   Gradle 8.7+
    *   JDK 11+
