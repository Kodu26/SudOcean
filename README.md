# SudOcean — Мобильное приложение для торговли (Интеграция с 1С)

**SudOcean** — это современное Android-приложение для автоматизации продаж морского оборудования с глубокой двухсторонней интеграцией в **1С:Предприятие**. Проект разработан как дипломная работа, фокусирующаяся на безопасности данных и отказоустойчивой синхронизации в B2B и B2C сегментах.

## 🚀 Основные возможности

### 👤 Управление пользователями
*   **Гибридная авторизация**: Приложение проверяет учетные данные сначала в локальной БД (Room), а затем в 1С. Это позволяет работать офлайн и обеспечивает актуальность аккаунтов.
*   **Принцип «1 логин = 1 аккаунт»**: Уникальность пользователей обеспечивается по `remoteId` (ИНН или телефон), синхронизированному с 1С.
*   **Автоматическое восстановление**: При регистрации система проверяет наличие контрагента в 1С. Если он помечен на удаление, он автоматически восстанавливается.

### 🛡 Безопасность (SudOcean Secure Protocol)
*   **Privacy Shield**: На экране оплаты активирован флаг `FLAG_SECURE`, запрещающий создание скриншотов и запись экрана.
*   **Криптозащита**: Пароли передаются и хранятся в защищенном виде (использование SHA-256 на стороне сервера).
*   **Проверка целостности**: Перед проведением транзакции приложение имитирует проверку TLS-соединения и целостности данных.
*   **Anti-Fraud**: Серверный контроль заказов и защита от спам-регистраций.
*   **Обфускация**: Системные токены и учетные данные скрыты от статического анализа.

### 🛒 Торговый функционал
*   **Динамический каталог**: Синхронизация товаров, цен и складских остатков в реальном времени.
*   **Умная корзина**: Валидация остатков перед оформлением заказа.
*   **Многоканальная оплата**: Поддержка прямых платежных ссылок и генерация QR-кодов для физических лиц.
*   **Документооборот**: Автоматическое формирование счетов в формате PDF в 1С и их загрузка в приложение.

## 🛠 Технологический стек

### Android (Frontend)
*   **Language**: Kotlin + Coroutines.
*   **Architecture**: MVVM, Clean Architecture (Repository pattern).
*   **Database**: Room (v8) с использованием уникальных индексов по `remoteId`.
*   **Network**: Retrofit 2, OkHttp (Interceptors для логирования и защиты).
*   **UI**: Jetpack Navigation, ViewBinding, SwipeRefreshLayout.

### 1С:Предприятие (Backend)
*   **API**: REST HTTP-сервис (`MobileExchange`).
*   **Logic**: Кастомные модули для обработки JSON-пакетов, управления статусами заказов и формирования PDF.

## ⚙️ Настройка и запуск
1.  **1С**: Опубликовать HTTP-сервис. Убедиться, что пользователю мобильного сервиса даны права на чтение/запись документов и справочников.
2.  **Android**: Настроить `BASE_URL` и `AUTH_TOKEN` в `NetworkClient.kt`.
3.  **БД**: При первом запуске Room автоматически создаст структуру (версия 8).
